# Sales & Operations MIS Dashboard

**Tools:** MS Excel, Power BI  
**Dataset:** 300 order records  
**Period:** January–June 2025

## Project objective
Analyze sales and operations data to monitor sales performance, order status, city/category performance, payment modes, and processing performance.

## Work completed / planned
- Cleaned and reviewed the Excel dataset.
- Created Excel-based MIS reporting structure and PivotTable-ready data.
- Loaded the dataset into Power BI.
- Created basic DAX measures including Total Sales, Total Orders, Completed Orders and Average Order Value.
- Planned an interactive Power BI dashboard with KPI cards, monthly sales trend, city-wise sales, category-wise sales, order-status analysis and slicers.
- Included `index.html` as a lightweight portfolio preview using the same project dataset.

## Dashboard preview
Open `index.html` with GitHub Pages to view the interactive portfolio preview.

## Important
The HTML page is a **portfolio preview**, not a replacement for the Power BI `.pbix` report. The repository is intended to document the project work and make the analysis easy to review without requiring Power BI Desktop.
